Buff Icon 색상 목업

배경 검정 + 흰 심볼 스프라이트에 색상 틴트를 적용한 경우 시뮬레이션

A — 현재 (원색 형광)

채도 높은 원색. 눈에 잘 띄지만 배경과 충돌감 있음

♟

B — 파스텔 다크 (채도 낮춤)

배경 어두운 색 + 부드러운 채도. 인게임 분위기에 자연스럽게 녹아듦

♟

C — 테두리 강조 + 어두운 배경

배경 단일 어두운 색 + 테두리 색으로 구분. 심플하고 정보 전달 명확

♟

D — 판타지 골드 계열

버프=골드, 디버프=다크레드, 상태이상=퍼플. 체스/판타지 분위기와 어울림

♟

E — 모노크롬 + 컬러 포인트

배경 회색 계열 통일, 심볼 색만 구분. 미니멀하고 세련됨

♟

F — 투명 배경 (참고용)

배경 없이 심볼만. 스프라이트를 투명 PNG로 교체하면 이렇게 됨

♟
